# Crossword

Aplicação web interativa para resolver palavras cruzadas com interface dinâmica e suporte a áudio. Uma experiência moderna e envolvente para praticar e desafiar sua habilidade com palavras.

### Objetivo

Oferecer uma experiência interativa de palavras cruzadas com foco em:

- resolução intuitiva de palavras cruzadas
- interface responsiva e adaptável
- suporte a múltiplos dispositivos
- experiência de usuário fluida e engajante

---

## Tecnologias Utilizadas

### Frontend

- React + Vite
- JavaScript
- CSS
- React Router DOM
- Bootstrap

### Bibliotecas Principais

- `react-simple-keyboard` - Teclado virtual
- `react-icons` - Ícones
- `jwt-decode` - Decodificação de tokens
- `media-chrome` - Controles de mídia

### Armazenamento

- `Cloudinary` - Armazenamento e reprodução de áudio

---

## Funcionalidades

- Resolução interativa de palavras cruzadas
- Reprodução de áudio (HTML5 nativo)
- Teclado virtual integrado
- Roteamento entre páginas
- Responsividade total
- Autenticação com JWT
